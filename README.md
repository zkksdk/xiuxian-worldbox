# 太虚演天 · 修仙世界模拟器

一款修仙题材的**上帝模拟器**（God Simulator）。你扮演「天道」，在程序化生成的修仙世界中播撒生灵、降下天劫、干预文明演化——然后看着这个世界自己运转：修士修炼、突破、结社、争斗、渡劫飞升。

> 参考《世界盒子》的观察式玩法，把生态与文明系统整体替换为修仙设定：**灵气场 / 灵脉龙脉 / 洞天福地 / 宗门正魔 / 境界渡劫 / 飞升轮回**。

---

## 一、如何运行

项目是**纯前端 ES Module 多文件结构**，零依赖、零构建、零外部资源（所有图标与纹理均由代码实时绘制）。

### 方式 A：本地服务器（推荐）

ES Module 受浏览器同源策略限制，**不能直接双击 index.html**，需要起一个静态服务器：

```bash
# Python 3（多数系统自带）
cd xiuxian-worldbox
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080

# 或者 Node.js
npx serve .

# 或者 VS Code 安装 "Live Server" 插件，右键 index.html → Open with Live Server
```

### 方式 B：应用内预览

若你在 Minis App 中，可直接打开：
`minis://workspace/xiuxian-worldbox/index.html`

### 方式 C：部署到静态托管

整个目录扔到 GitHub Pages / Vercel / Netlify 即可，无需任何构建步骤。

## 三、玩法速览

### 观察
- **世界自发运行**：修士自己找灵气高的地方打坐、突破、结社、争夺灵脉、正魔厮杀。
- **左侧选神力 → 地图上点击/拖动施放**，消耗「天道之力」（随时间恢复）。
- **右侧面板**：世界概览 / 境界榜（含资质）/ 宗门录 / 单位详情（点地图单位）。
- **底部大事记**：宗门成立、渡劫、飞升、战争、天灾，按类型着色。

### 操作（触屏 / 鼠标通用）
| 操作 | 方式 |
|---|---|
| **平移镜头** | 单指拖动（未选神力时）· **双指同时拖动**（任何时候都能用）· 鼠标拖动 · `WASD` |
| **缩放** | **双指捏合** · 滚轮 · 右下角 `＋` `－` 按钮 |
| **✋ 移动模式** | 右下角手掌按钮：强制单指拖动镜头（选了神力也能拖），选神力时自动退出 |
| 施放神力 | 选中神力后，点击或拖动地图 |
| 选择单位 | 未选神力时点击地图上的单位 |
| 双击单位 | 视角居中到该单位 |
| 快捷键 | `空格` 暂停 · `1-5` 切换视图 · `[` `]` 调速 · `Esc` 取消神力 |

> 触屏手势要点：**双指既能缩放也能平移**（两指同向移动=平移，两指开合=缩放）；双指抬起一根手指后，剩下的手指可以继续拖动，不会中断。画布已设置 `touch-action: none`，浏览器不会抢走手势。

> **放大到 4.6 倍以上会显示修士名号，5.5 倍以上显示资源点标签**，并且地形会展现程序化纹理（草簇、岩石粒、冰晶、灵光点）。

### 五种视图
**地形** · **灵气**（热力图）· **魔气** · **宗门**（势力领地）· **资源**（灵脉/矿脉/灵田/药谷/洞天）

### 19 种神力
- **地形**：造山、沉降、点石成金（造矿脉）
- **灵气**：注灵、抽灵、魔染、灵雨
- **生灵**：播撒修士、播撒妖兽、播种灵植
- **天罚**：雷劫、焚天火劫、九幽风劫
- **点化**（先选中单位）：点化（+1 小境界）、护道（渡劫+30%）、心魔（渡劫-50%）、赐宝、传功、轮回

## 四、核心系统

### 境界体系
九大境界，每境四小阶段，跨大境界须**渡劫**：

| 境界 | 寿元 | 修炼速度 | 突破需求 | 战力 |
|---|---|---|---|---|
| 炼气 | 120 | 1× | 100 | 1× |
| 筑基 | 200 | 2× | 500 | 5× |
| 金丹 | 500 | 4× | 2,000 | 25× |
| 元婴 | 1000 | 8× | 8,000 | 100× |
| 化神 | 2000 | 16× | 30,000 | 500× |
| 炼虚 | 5000 | 32× | 100,000 | 2,500× |
| 合体 | 10000 | 64× | 350,000 | 10,000× |
| 大乘 | 30000 | 128× | 1,000,000 | 50,000× |
| 渡劫 | — | — | 飞升之劫 | — |

**时间轴设计**：1× 速度下 1 真实秒 = 1 世界年。炼气→筑基约 1 分钟，元婴约需 15 分钟，**飞升通常要 8000～15000 年**（20× 速度下约 7～12 分钟）——后期极难，飞升是稀有事件。

### 资质（灵根）
**每个修士出生自带灵根**，决定修炼速度与突破成功率：

| 灵根 | 权重 | 修炼系数 | 突破加成 | 评级 |
|---|---|---|---|---|
| 天灵根 | 3% | ×1.55 | +20% | ★★★★★ |
| 变异灵根 | 5% | ×1.35 | +15% | ★★★★☆ |
| 单灵根 | 14% | ×1.22 | +10% | ★★★☆☆ |
| 双灵根 | 26% | ×1.08 | +5% | ★★☆☆☆ |
| 三灵根 | 27% | ×0.98 | 0 | ★☆☆☆☆ |
| 四灵根 | 17% | ×0.86 | −7% | ★☆☆☆☆ |
| 五灵根 | 8% | ×0.72 | −15% | ☆☆☆☆☆ |

妖兽有 **1～5 阶血脉**、灵植有 **一品～六品灵性**，同样以星级呈现。
「轮回」神力可让修士**灵根纯度提升一档**（五灵根→四灵根……）——这是玩家塑造天骄的主要手段。

### 灵根之外的影响因素
- **道心**（0-100）：随修炼缓慢增长，历练/悟道大涨，影响突破稳定性
- **灵气浓度**：`灵气>80 → 突破+18%`，`<20 → −25%`
- **功法**（黄/玄/地/天/仙五阶）：提升修炼速度与战力
- **法宝**（凡器→仙器六阶）：提升战力
- **宗门护法**：门中人多时渡劫 +6%
- **奇观加成**：北斗灵枢范围内渡劫 +10%
- **丹药**：聚气丹 / 筑基丹 / 渡劫丹等

### 渡劫与飞升
- 大境界圆满且修为溢满 → 自动引动天劫（五行雷劫 / 九天玄劫 / 心魔劫），**全屏雷电特效 + 世界公告**
- 渡劫期间玩家可「护道」（+30%）或「心魔」（−50%）——**这是天道的直接干预**
- 成功：晋阶 + 返老还童（寿元基准重置）
- 失败：30% 陨落 / 50% 跌落境界 / 20% 道基受损
- **大乘圆满后渡劫成功即为飞升**：霞光万丈、全服公告、**留下仙缘永久提升周围灵气**

### 地表植被
地图上生长着约 **8000 株**程序化生成的草木石竹，按群系分布：
阔叶树 / 松树 / 枯木 / 灌木 / 岩石 / 野花 / 草簇 / 仙人掌 / 灵晶 / 灵莲 / 灵菇 / 青竹 / 骸骨 / 芦苇，
共十套配色（温带 / 深林 / 寒带 / 荒漠 / 雪原 / 魔渊 / 洞天 / 药谷 / 灵田 / 海滨）。

- 森林是密林、雪原是雪松与冰晶、沙漠是仙人掌、魔渊是紫色扭曲魔木、洞天是灵光草木
- 每株草木由种子确定性绘制（形态、大小、配色都有差异），**烘焙进地形图**——渲染零额外开销
- **可被生物与天灾摧毁**：修士会顺手砍伐周边草木（伐木得**木料**、采药得**灵草**、凿石得**矿石**，低阶弟子更常亲自动手）；妖兽觅食会啃食植被；元婴以上修士斗法会**摧毁四野草木，大能交手甚至把地面打凹**；火劫烧毁草木（日志报"焚毁草木 N 株"），灵雨让枯木逢春
- **会自己长回来**：被砍伐的草木在灵气 >38 的地方有概率重新萌发（每年抽查 8 个区块，避免全量遍历），灵气越足恢复越快
- **地貌会被"用"出来**：露天开采矿脉会把山体挖矮（储量低于 70 后开始塌陷），大能交手留下焦土坑 ——**地图不是一成不变的背景板**

### 修士有脑子：性格基因 + 道统网络 + 进化筛选
不再是"千人一面的 if-else"，每个修士都是独立个体：

**① 性格基因（4 维）**：谨慎 / 好战 / 贪婪 / 好奇
- 决策时作为倍率作用于七路行为的倾向分（`score[争锋] × (0.35 + 好战×1.7)` 等）
- 详情卡会翻译成人话：**「莽撞·贪婪·好奇」「谨慎·平和」「中庸」**…
- **门风传承**：弟子入宗时性格向宗主靠拢 32% + 变异，于是血影宗出莽夫、太虚宗多清修

**② 道统网络（轻量神经网络）**：24 输入 → 18 隐藏(tanh) → 7 输出
- 输入 = 自身状态 8 维 + 环境 7 维 + 社会 5 维 + 记忆 4 维（含性格本身）
- 输出 = 遁走/苦修/争锋/探秘/拓业/冲关/游历 的**偏好倍率**（tanh→[0.62,1.38]）
- **网络只做偏好偏移，规则分做骨架** —— 即使网络退化也不会犯蠢

**③ 十六套"道统"（权重池）**：全服只维护 16 份权重（36KB），单位引用其一
- 避免"每单位一个网络"的内存爆炸
- **每 50 年评选一次**：按使用者的平均境界/战绩/财富算适应度，淘汰最差 30%，用最优者复制 + 5% 变异补齐
- 大事记会公告「☯ 道统更替：『赤阳道』继『长生道』之法，已传至第 2 代」——**世界在自己筛选活法**
- 右面板新增「**道统**」页签，实时看 16 门道统的适应度排行、传承代数与门徒数

**④ 记忆**：记仇（被打 +2 仇恨）、危险点、好修炼点

### 关系网：师徒 · 道侣 · 血仇
修士之间会结下真实的关系（详情卡可见）：

| 关系 | 结成条件 | 效果 |
|---|---|---|
| **师徒** | 同门中，对方高出自己两个大境界且收徒未满 5 人 | 弟子修炼 **+15%**，师父因**教学相长 +3%~12%** |
| **门下** | 同上（反向） | 师父陨落时全体弟子背负血仇 |
| **道侣** | 境界相差 ≤1、皆未婚配、同门或散修，13 格内相遇 | 双方修炼 **+12%**；一方遇害，另一方道心 -15 并**誓死复仇** |
| **血仇** | 师父/道侣/弟子被某人杀害 | 记恨凶手（仇恨 +8）、`avenge` 标记，遇仇人时倾向 **×1.85**（普通记仇 ×1.35） |

大事记会播报：「✦ 某某 收 某某 为徒（化神·初期）」「❀ 某某 与 某某 结为道侣，此后携手同修」「⚔ 某某 陨落，其师门誓要寻 某某 雪仇」。

实测 600 年：**57 人有师承 · 25 人有弟子 · 42 人结道侣 · 11 人身负血仇**。

**实测**：600 年演化后行为明显分化（苦修 46 / 探秘 60 / 拓业 23 / 争锋 10 / 遁走 3），性能仅 **1.63 ms/世界年**。

### 一个"活"的世界
```
草木被砍 → 消失 → 灵气滋养 → 重新萌发
山被挖   → 变矮 → 地貌永久改变
修士采集 → 得木料/灵草/矿石 → 服食化修为
斗法     → 草木尽毁 + 地陷
```

实测 400 年：**303 株草木被毁、180 格地形被改变、105 名修士采得木料 204 / 灵草 542 / 矿石 266**。
- 相关模块：`js/decor.js`（14 种绘制器 + 精灵缓存）

#### 前后遮挡层次
修士会被**站在他前方**的树冠遮住，形成纵深——走在小树林里的修士会有"忽隐忽现"的感觉。

实现方式（`Renderer._occludeUnit`）：草木本身烘焙在地形图里（零成本），但**每绘制一个单位后**，会从 8 格粒度的空间网格 `bigDecorGrid` 中取出该单位附近"根部 y 大于自己"的大树重绘一遍。由于重绘坐标与烘焙坐标**经过推导完全重合**，不会产生位移或重影。实测每帧只增加约 1ms（252 单位时总渲染 4.8ms）。

### 世界生态
- **灵气场**：山海之间灵气不均；灵眼（富集）与绝地（枯竭）散布；修士打坐会吸收当地灵气导致局部衰减，会缓慢自然恢复
- **龙脉**：从灵势峰值沿最陡下降追踪出的地脉线路，滋养沿途灵气（地图上呈现蜿蜒微光）
- **资源点**：灵脉（产灵石）、矿脉（铁/铜/银/金/玄铁/寒铁/星辰铁）、灵田、药谷、洞天福地、魔渊

#### 资源绝不凭空产生（完整闭环）
每个资源点都有**储量**（0~100）与**再生速率**，开采即消耗：

| 资源点 | 再生速率/年 | 说明 |
|---|---|---|
| 灵田 | 1.0 | 草木自生，恢复最快 |
| 药谷 | 0.8 | 药性天地滋养 |
| 洞天福地 | 0.65 | 灵气充盈 |
| 灵脉 | 0.45 | 地气汇聚 |
| 魔渊 | 0.3 | 魔气凝积 |
| **矿脉** | **0.18** | 极慢——所以矿产才珍贵 |

**完整链条**：
```
天地灵气 → 灵植生长 → 结出灵草 → 修士采食 → 修为提升
灵脉/矿脉 → 宗门开采 → 灵石 → 门人俸禄 + 扩张本钱
开采过度 → 地力枯竭（事件公告）→ 需静待恢复 → 或去抢别人的
```
- **宗门收入 100% 来自领地内的资源点**（旧版有一项"按门人数白给灵石"的凭空收入，已删）——没有地盘就没有进项，这正是宗门拼命扩张、开战的根本动力
- 储量低于 25% 后产出线性衰减；归零则**枯竭**并全服公告，须等恢复到 35% 才能复工
- 灵植被采集后**重新生长**（`mature=false, grow=0.25`），不会连续产出
- 实测 600 年：117 个资源点中 **29 个被采到枯竭**，宗门财富与地盘严格正相关（22 块地 → 9809 石 vs 4 块地 → 1137 石）
- **正魔分化**：魔气区突破有几率堕入魔道；正道在魔气区修炼效率减半，魔修靠吞噬他人精血暴涨修为
- **宗门**：金丹以上可立宗，招收弟子、占据资源、正魔之间自动敌视
- **疆土是门人亲自去打的**：宗门会**派遣弟子**前往领地前沿立桩拓土——你能在图上看到某个修士孤身走向荒野，抵达后"⚑ 拓土 9 里"，那片地才归入宗门版图。派遣频率、同时出征队伍数、拓土范围都取决于门人数量与宗门等级
  - 门人越多 → 能同时派出的拓荒队越多；弟子境界越低越容易被派出去（长老留守）
  - 拓荒队受地形阻挠：高山雪峰 55% 通过、绝灵之地 35%、魔渊 12%，**遇海止步**
  - 因此版图天然奇形怪状：绕开山脊、沿海岸线延展、顺着灵气富集区铺开，**同一个宗门还可能被山海劈成互不相连的两块飞地**
  - 另有极低概率的"自然归附"（边民依附），保证无人可派时不至于完全停滞
  - 实测：赤霄院 12 人拓得 377 里，少阳院 9 人 156 里 —— **疆域大小直接反映宗门实力**
- **战争割地**：战胜方按"距离就近"原则吞并败方约 **22%** 的疆土（不是简单抢一个资源点），版面会像被啃掉一块
- **凡人觉醒**：灵气充沛之地会持续有凡人觉醒灵根踏上仙途，维持世界的新生力量

#### 生态平衡（治"世界失衡"）
长期演化后容易出现三种失衡，均有对应机制压制（实测 3500 年数据）：

| 症状 | 机制 |
|---|---|
| **妖兽被屠尽** | 妖兽容量随修士规模浮动（`max(90, 修士×0.55)`）；凶兽**无偶亦可产仔**；修士越盛"杀气越重"，凶兽**进化更快**（压力驱动的进化） |
| **境界通胀**（人人化神） | **化神以上每百余年遭一次心魔劫**：8% 陨落 / 34% 跌境 / 余者道心更坚 |
| **魔道绝迹** | 心魔劫失败有 **30% 概率不是跌境而是堕魔**（魔道主要来源）；魔渊持续渗出魔气；世界事件会随机"地脉破裂，魔渊现世" |
| **兽潮过弱** | 兽潮规模与修士数量挂钩（`修士/60 + 2` 头，三阶以上为主） |

实测 3500 年：修士 339 · **妖兽 185** · **魔修 76**（22%）· 顶尖高手中魔道与正道分庭抗礼。

## 五、性能与实现要点

- **SoA + TypedArray**：地形/灵气/魔气/群系等标量场用 `Uint8Array` / `Float32Array` 连续存储
- **地形分块脏重绘**：地形预渲染到 2048×2048 离屏画布，按 16×16 格分块，**只重绘发生变化的区块**（笔刷、天劫、地形神力均只标记脏块）
- **五档渲染预算**：根据脏块积压动态调整每帧重建块数（3 / 6 / 14），避免卡顿
- **低频更新**：灵气/魔气叠层 0.55～1.8 秒刷新一次；灵气回归采用 8 组分帧轮转；世界年度逻辑与渲染帧解耦
- **预热图与缓存**：单位精灵、径向光效、UI 图标全部预渲染缓存，避免每帧创建渐变对象
- **时间步长解耦**：渲染帧用真实 dt，世界演化按「世界年」累积补算（单帧最多 24 年），支持 1×～20× 且不丢帧
- **异常隔离**：主循环 try/catch，单次异常不会中断世界演化；`window.__errs` 收集所有运行时错误便于排查

### 单位数量无上限（分级降载）
世界不限制单位数量，靠四层机制扛住规模：

| 机制 | 做法 |
|---|---|
| **空间网格** | 12 格粒度的单位哈希网格，`_findFoe`／妖兽择偶／立宗招募从 **O(n) 全表扫描降到 O(邻近格)** —— 这是最关键的一步（旧实现在 1000 单位时每个决策都要扫 1000 次） |
| **决策降载** | 单位越多思考越"懒"：<320 时 1~3 年决策一次；<900 时 2~5 年；更多则 4~10 年（行为模式不变） |
| **分帧推进** | 超过 1200 单位时年度逻辑分 4~8 组轮转（时间跨度按倍数补偿）；超过 2200 单位时帧更新分 2~3 批 |
| **渲染采样** | 超量时按 id 稳定采样（不闪烁，战斗/高境界/选中单位始终绘制）；大量单位+小缩放时用色块代替精灵图；遮挡重绘自动关闭 |

实测（移动端 WebView 沙箱）：

| 规模 | 年度逻辑 | 每帧（模拟+渲染） |
|---|---|---|
| ~400 单位 | 1.4 ms | ~5 ms |
| ~7900 单位 | **7.3 ms** | **30 ms**（约 33fps） |

对照组：优化前的实现在 6000 单位时年度逻辑 17ms、每帧 **166ms**（6fps）。

## 六、调参与扩展

所有平衡数值集中在 **`js/config.js`**：

```js
CFG.balance = {
  cultSpeedBase: 4.2,        // 修炼速度全局倍率
  stageNeedMul: [0.30, 0.45, 0.58],   // 小阶段需求系数
  realmBreakNeedMul: 0.30,   // 跨大境界需求系数
  breakBase: 0.62,           // 小阶段基础成功率
  tribBase: 0.50,            // 渡劫基础成功率
  ...
};
CFG.sect.war = 0.011;        // 宗门开战频率
CFG.world.TILE = 8;          // 地形精细度（越大放大越清晰，显存换精度）
```

- 想换世界尺寸：改 `CFG.world.W / H`（默认 256×256，建议 192～384）
- 想换种子：改 URL 参数 `?seed=12345`，或调用 `XW.newWorld(seed)`
- 想加新神力：在 `js/powers.js` 的 `POWER_LIST` 加一条，并在 `Powers.use()` 的 switch 里补一个分支（图标绘制在 `js/icons.js` 的 `drawPower`）

### 存档
- 自动保存：每 45 秒 + 页面关闭时写入 `localStorage`
- 手动：顶栏 💾 按钮
- 导出的 JSON 含完整世界（地形/灵气/单位/宗门/事件），可直接在控制台 `XW.save.exportFile()` 导出
